## 功能特性

- ✅ **学生端自动发现** - 支持网段扫描，快速发现局域网内学生端
- ✅ **远程执行命令** - 批量执行任意程序（calc.exe、cmd等）
- ✅ **批量关机/重启** - 一键控制所有学生端电源
- ✅ **弹窗消息推送** - 向学生端发送自定义弹窗
- ✅ **Web图形化界面** - 浏览器访问，操作简单直观
- ✅ **批量操作** - 支持全选/选在线，批量发送
- ✅ **操作日志** - 实时记录所有操作
- ✅ **多线程发送** - 高性能批量UDP发包

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python app.py
```

### 访问界面

打开浏览器访问: `http://localhost:5000`

## 使用说明

### 1. 扫描学生端
- 在输入框中填写网段（如 `192.168.1.0/24`）
- 点击「扫描学生端」按钮
- 等待扫描完成，列表会显示发现的学生端

### 2. 选择学生端
- 点击表头复选框全选
- 或使用「选在线」只选择在线的机器
- 单个选择点击每行前面的复选框

### 3. 执行操作

**远程执行：**
- 输入程序路径（如 `calc.exe`）
- 可选输入参数
- 点击「执行命令」

**发送消息：**
- 输入消息内容
- 点击「发送弹窗」

**电源控制：**
- 点击「关机」或「重启」
- 确认后批量执行

## 技术细节

### 协议端口

| 端口 | 协议 | 用途 |
|---|---|---|
| 4705 | UDP | 远程执行命令 |
| 7005 | UDP | 关机/重启 |
| 7006 | UDP | 弹窗消息 |
| 7000 | UDP | 学生端发现 |

### 组播地址

| 地址 | 用途 |
|---|---|
| 224.50.50.42 | 教师端发现广播 |
| 225.2.2.111 | 控制组播 |
| 225.2.2.11 | 屏幕广播 |

### DMOC数据包

- 包头签名: `DMOC` (44 4D 4F 43)
- 远程执行包: 906字节
- 关机包: 622字节
- 编码: UTF-16LE宽字符
