## 功能特性

### 极域原生兼容（V6版）
- ✅ **学生端自动发现** - UDP 7000组播监听
- ✅ **远程执行命令** - DMOC协议伪造，端口4705
- ✅ **批量关机/重启** - UDP 7005
- ✅ **弹窗消息推送** - UDP 7006
- ✅ **V4.2版兼容** - KACA包头，端口4605/11144

### 自研屏幕监控/广播
- ✅ **屏幕监控** - 学生代理截屏上传，Web端实时网格查看
- ✅ **屏幕广播** - 教师端屏幕推送到学生代理全屏显示
- ✅ **多学生同时监控** - 网格视图

### 其他
- ✅ **Web图形化界面** - 浏览器访问，操作简单
- ✅ **批量操作** - 全选/选在线，批量发送
- ✅ **操作日志** - 实时记录所有操作
- ✅ **多线程发送** - 高性能批量UDP发包
- ✅ **Windows exe打包** - 一键打包成可执行文件

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动教师端

```bash
python app.py
```

浏览器访问: `http://localhost:5000`

### 启动学生端代理（屏幕监控/广播用）

```bash
python student_agent.py --teacher http://教师端IP:5000
```

## 使用说明

### 极域控制功能
1. 在输入框填写网段，点击「扫描学生端」
2. 勾选要控制的学生机
3. 执行：远程执行/发送消息/关机/重启

### 屏幕监控
1. 学生机运行 `student_agent.py`
2. 教师端切换到「屏幕监控」标签页
3. 自动显示所有在线学生的屏幕缩略图

### 屏幕广播
1. 学生机运行 `student_agent.py`
2. 教师端切换到「屏幕广播」标签页
3. 点击「开始广播」
4. 学生机将自动全屏显示教师端屏幕

## Windows exe打包

在Windows环境下运行：

```bash
build_exe.bat
```

生成文件：
- `dist\MythwareTeacher.exe` - 教师端主程序
- `dist\MythwareStudentAgent.exe` - 学生端代理

## 协议技术细节

### V6版端口分配

| 端口 | 协议 | 用途 |
|---|---|---|
| 7000 | UDP | 教师心跳/学生发现 |
| 4705 | UDP | 远程执行命令 |
| 7005 | UDP | 关机/重启/锁屏 |
| 7006 | UDP | 弹窗/签到 |
| 7001 | TCP | 屏幕监控/文件下发 |
| 7003 | TCP | 远程控制 |

### V4.2版端口分配

| 端口 | 协议 | 用途 |
|---|---|---|
| 2355/4605 | UDP | 学生端通信 |
| 2356/11144 | UDP | 屏幕数据 |
| 2357 | TCP | 控制连接 |

### 组播地址

| 地址 | 版本 | 用途 |
|---|---|---|
| 224.50.50.42 | V6 | 教师端发现 |
| 225.2.2.111 | V6 | 控制组播 |
| 225.2.2.11 | V6 | 屏幕广播 |
| 224.60.60.42 | V4 | 教师端发现 |
| 225.2.13.1 | V4 | 屏幕广播 |

### DMOC数据包（V6版）

- 包头: `DMOC` (44 4D 4F 43)
- 远程执行包: 906字节
- 关机包: 622字节
- 编码: UTF-16LE宽字符
